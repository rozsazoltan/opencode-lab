# Agent guidance

## Purpose

This repository shares personal experience with AI, especially OpenCode. It collects practical lessons, setup choices, preferences, and related work so readers can understand what worked, why, and what they might adapt. This is an informational collection, not a software product or a promise of tool support.

## Content

- Write plain, useful explanations. Distinguish observed behavior from personal preferences, opinions, and experiments. Give relevant context and limits rather than presenting one setup as universally correct.
- Verify external factual claims against reliable sources, preferably official documentation, and link the supporting sources. Check compatibility when a change depends on a particular tool or environment. Do not invent commands, features, results, or checks.
- Explain the practical reason for including a resource or example. Avoid promotion, exaggerated claims, and explanations already covered in reader-facing documentation.

## Editing

Read existing content and applicable instructions before editing. Match established conventions and keep changes focused on the request. Preserve unrelated work.

Do not add build systems, application architecture, or implementation scaffolding unless requested and justified by the repository's actual needs.

Make public configurations and examples safe to share and reproducible. Use clearly labeled placeholders for secrets and machine-specific private details, and explain necessary prerequisites. Do not publish credentials or private data.

## Validation

Review changed prose for clarity, accuracy, and Markdown formatting. Check referenced links and commands when relevant and feasible. Verify examples without assuming this collection has a build or test workflow. Run only checks supported by the repository and proportionate to the change.

Review the final diff for unintended changes. Briefly report what changed, what you actually verified, and any unresolved items. Never describe an unrun check as successful.
