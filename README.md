# opencode-lab

Notes from my work with AI, especially OpenCode: practical lessons, setup choices, preferences, and related projects. This is a personal, informational collection—not a software product or a promise of support.

## Current workflow

I currently pair VS Code with the [OpenCode Desktop app on its `v2` branch](https://github.com/anomalyco/opencode/tree/v2) (beta). I like its GUI, and its automatic WSL distribution setup suits how I work across distros. OpenChamber's [published setup steps](https://github.com/openchamber/openchamber#quick-start) don't describe automatic WSL distribution installation. In my multi-distro workflow, manual setup adds steps I try to avoid. This is my experience, not a universal recommendation.

## Projects

- [opencode-sherpa](https://github.com/rozsazoltan/opencode-sherpa) — CLI for syncing reusable OpenCode instructions, skills, commands, MCP entries, and optional OMO-Slim specialists.
- [opencode-dev](https://github.com/rozsazoltan/opencode-dev) — Handcrafted agents, skills, and workflows for my daily development stack.
- [opencode-caveman](https://github.com/rozsazoltan/opencode-caveman) — Thin OpenCode V2 adapter for the upstream [Caveman](https://github.com/JuliusBrussee/caveman) project.
- [opencode-playwright](https://github.com/rozsazoltan/opencode-playwright) — OpenCode plugin that manages a Playwright MCP bridge between Windows and WSL.

Each project is maintained separately. See its own repository for current details.
